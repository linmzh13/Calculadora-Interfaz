# Calculadora en Python con Tkinter

## Descripción

Este proyecto consiste en una calculadora básica desarrollada en Python utilizando la librería Tkinter, que permite crear interfaces gráficas. La calculadora cuenta con una pantalla donde se muestran los números y las operaciones que se realizan.

## Funciones principales

- Ingresar números del 0 al 9.
- Realizar sumas, restas, multiplicaciones y divisiones.
- Mostrar las operaciones en la pantalla.
- Calcular y mostrar el resultado.
- Limpiar la pantalla con el botón `C`.
- Mostrar un mensaje de error cuando se intenta dividir entre cero o se ingresa una expresión no válida.

## Tecnologías utilizadas

- **Python:** lenguaje de programación utilizado para desarrollar el programa.
- **Tkinter:** librería utilizada para crear la interfaz gráfica.

## Ejecución del programa

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Abrir una terminal en la carpeta del archivo.
4. Ejecutar el archivo `calculadora_tk.py`
5. Se abrirá la ventana de la calculadora y se podrá empezar a utilizar.

## Uso de la calculadora

1. Presionar los botones numéricos para ingresar los valores.
2. Seleccionar la operación que se desea realizar.
3. Presionar el botón `=` para obtener el resultado.
4. Utilizar el botón `C` para limpiar la pantalla y realizar una nueva operación.
